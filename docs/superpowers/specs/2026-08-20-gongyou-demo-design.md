# 《工友》桌面 Demo 设计规格

## 1. 目标

制作一个可在 Windows 10/11 上真实运行的 Electron Demo，用 5 分钟路演证明《工友》的核心价值：它会陪伴用户上班、接住用户情绪、记得用户说过的话，并把工作时间、小成就和实时工钱变成可见的积累。

首版优先保证演示故事完整、交互反馈及时、无网可降级，不追求 PRD 中所有模块同时交付。

## 2. 已确认的产品决策

- 核心卖点：情绪陪伴，让用户感到“被接住、被记得”。
- 产品形态：真实 Electron 桌面应用，而非仅模拟桌面的网页。
- AI：调用真实 AI，失败、超时或无配置时使用本地模板兜底。
- 记忆：倾诉保存到本地记忆瓶；关闭再打开后，工友可主动提起旧事。
- 联网边界：首版不做局域网发现、聊天和对战。
- 界面模式：“工友中心型”，所有能力由同一个角色和它的工位带出。
- 办公辅助：首版包含番茄钟、小事打卡、备忘录、久坐和喝水提醒。
- 工资：首版仅支持月薪，用户设置月薪、每周工作日、上下班时间、午休时间和每月发薪日。
- 发薪日：按用户设置的自然日计算，不因周末自动提前或顺延；当月不存在该日期时使用当月最后一天。

## 3. Demo 边界

### 3.1 首版包含

1. 透明无边框的工友悬浮窗，可拖动、可置顶。
2. 像素工友的待机、倾听、专注、困倦和庆祝状态反馈。
3. 情绪树洞：倾诉输入、AI 共情回应、本地兜底、记忆瓶、跨启动主动提起。
4. 实时工钱：今日已挣金额逐秒跳动，保留两位小数。
5. 发薪倒计时：显示下一发薪日和剩余天数，发薪日触发工友庆祝。
6. 下班倒计时与加班语气切换。
7. 番茄钟：默认 25 分钟专注、5 分钟休息，支持开始、暂停、继续和重置。
8. 小事打卡：记录今天完成的一件事，工友给出即时肯定，主页显示当日完成数。
9. 备忘录：新增、编辑、完成、删除，可选本地提醒时间。
10. 久坐和喝水提醒：可配置间隔，通过工友气泡、打工列车广播和系统通知呈现。
11. 整点广播：展示实时工钱、下班倒计时、备忘提醒、身体关怀和工友的话。
12. 全局快捷键隐藏/恢复所有窗口，系统托盘可唤回应用。
13. 本地设置和数据持久化。
14. 演示模式：可手动立即触发广播、身体提醒、下班和发薪庆祝，避免路演等待真实时间。

### 3.2 首版不包含

- 局域网、聊天和对战。
- 复杂养成数值、等级曲线、物品稀有度和完整装扮商店。
- 多种薪资模式、税费、社保公积金、法定节假日和公司调休计算。
- 云同步、账号系统、多设备数据。
- 备忘录分类、搜索和多人共享。
- 记忆瓶搜索和完整情绪分析。
- 自动更新和多语言。

## 4. 窗口与界面

### 4.1 工友悬浮窗

- 透明、无边框、可拖动，默认停在右下角。
- 主体为像素工友；旁边显示一个紧凑状态条。
- 状态条可在“今日工钱”和“距下班时间”间切换。
- 单击工友展开主窗口，右键打开快捷菜单，拖动改变位置。
- 工友状态由当前时间、番茄钟、用户倾诉和提醒事件共同驱动。

### 4.2 工友主窗口

主界面是一张“工友的工位”，不使用传统办公后台式多级导航。

- 记忆瓶：倾诉入口与最近记忆。
- 桌面钟：番茄钟入口与进度。
- 打卡章：快速记录小事。
- 便签板：备忘清单。
- 工资袋：今日工钱、今日预计、距下班时间、下次发薪日。
- 水杯与工位椅：喝水和久坐提醒入口。
- 工友本体：点击、摸头、查看状态与当前气泡。

### 4.3 打工列车广播

- 以深蓝、米白和珊瑚橙为主色，使用站点、进度线和广播文案形成仪式感。
- 自动显示 5–8 秒后收起，用户也可立即关闭。
- 会议或免打扰模式下不展示全屏广播，仅保留系统通知。

### 4.4 设置中心

设置中心收纳工作时间、薪资、发薪日、提醒间隔、快捷键、窗口置顶和 AI 会话配置。主界面不直接堆叠这些表单。

## 5. 核心交互流程

### 5.1 首次启动

1. 选择每周工作日。
2. 设置上下班和午休时间。
3. 输入月薪和每月发薪日。
4. 设置久坐、喝水和广播间隔。
5. 选择工友性格：默认使用“嘴硬心软的老友”。
6. 说明倾诉数据保存在本地；启用真实 AI 时，当前倾诉和最多一条相关记忆会发送到用户配置的 AI 端点。

### 5.2 倾诉与记忆

1. 用户点击记忆瓶，输入一句或一段心里话。
2. 工友进入倾听状态，展示不夸张的等待动画。
3. AI 以固定人设输出 1–3 句短回应：先共情，再可选给出一点轻建议，禁止说教和空洞鸡汤。
4. 回应与倾诉一起写入本地记忆瓶。
5. 下次启动时，若存在过去 7 天内且尚未被主动提起的记忆，工友优先问候最近一条，并将其标记为已提起。

### 5.3 实时工钱

1. 根据当月用户选中的工作日数计算当日工资：`dailyPay = monthlySalary / scheduledWorkdaysInMonth`。
2. 根据上下班时间与午休区间计算当日有效工作秒数。
3. 上班前今日工钱为 0；工作时段内逐秒增长；午休时暂停；下班后固定为当日预计值。
4. 非选中工作日时今日工钱为 0，工友显示休息语气。
5. 仅计算名义时间工资，不计算税费、请假、加班费和节假日。

### 5.4 发薪倒计时

- 当月发薪日尚未到来时，使用当月发薪日；已经过了时使用下月发薪日。
- 设置日超过当月天数时，使用当月最后一天。
- 不根据周末或节假日移动日期。
- 发薪日当天首次启动或跨过零点时，仅庆祝一次。

### 5.5 番茄钟、打卡与备忘录

- 番茄钟状态包含未开始、专注、暂停、休息和完成。完成一个专注段时自动记录一次专注，工友进入庆祝状态。
- 小事打卡允许输入 1–80 字；当日列表按时间倒序展示。
- 备忘录的提醒时间为可选字段；到点时触发系统通知和工友气泡，会议模式下不弹全屏广播。
- 删除操作需二次确认；完成备忘时给出短动画和一句肯定。

### 5.6 身体关怀与广播

- 久坐间隔默认 60 分钟，喝水间隔默认 45 分钟，均可关闭。
- 用户主动确认“我起来了”或“已喝水”后，重新开始对应计时。
- 广播默认每 60 分钟触发；根据当前状态选择一个主题，优先级为：到期备忘 > 发薪/下班事件 > 身体关怀 > 记忆问候 > 普通工钱进度。

## 6. 演示剧本

1. 启动应用，桌面角落的工友正在待机，今日工钱逐秒增长。
2. 点击工友打开工位主窗口，展示下班与发薪倒计时。
3. 记录一件小事，工友立即肯定。
4. 开始一个番茄钟，工友进入专注状态。
5. 输入“方案被改了五版”，演示真实 AI 共情回应和记忆瓶保存。
6. 使用演示按钮触发一次打工列车广播，将工钱、下班倒计时和工友的话放在同一个仪式中。
7. 关闭并重新打开应用，工友主动问“刚才那件事后来怎么样了？”
8. 触发下班或发薪日演示，以庆祝动画收尾。

## 7. 技术架构

### 7.1 技术栈

- Electron + TypeScript。
- React + Vite 负责渲染进程 UI。
- Vitest 负责纯领域逻辑和组件测试。
- Playwright/Electron 冒烟测试验证窗口、启动与关键流程。
- 本地 JSON 存储作为 Demo 持久化方案，通过原子替换写入；不引入 SQLite 和原生数据库依赖。

### 7.2 进程边界

**主进程**负责：

- 悬浮窗、主窗口、广播窗口和托盘。
- 单实例锁、全局快捷键、系统通知。
- 持久化、绝对时间调度、系统休眠后重新校准。
- AI HTTP 调用与超时降级。

**预加载层**只暴露类型化、最小化的 IPC API，不向渲染进程暴露 Node.js。

**渲染进程**负责：

- UI、像素动画、工友状态呈现和用户输入。
- 通过 IPC 读写状态、启动计时器、请求 AI 回应和触发系统级操作。

### 7.3 领域模块

- `salary`：工作日、有效时间、逐秒工钱、下班与发薪倒计时。
- `companion`：工友状态机、性格语气和事件响应。
- `memory`：记忆瓶保存、最近记忆选择和主动提起。
- `focus`：番茄钟状态与时间计算。
- `tasks`：打卡与备忘录。
- `reminders`：久坐、喝水、备忘和广播优先级。
- `ai`：提示词构造、OpenAI 兼容请求、输出清洗和本地兜底。
- `storage`：配置版本、验证、迁移和原子写入。

## 8. 数据流与隐私

- 薪资、工作时间、备忘、打卡、番茄记录和记忆瓶默认仅保存在用户本机应用数据目录。
- 应用无账号、无遥测、无云同步。
- 首次使用 AI 前显示明确提示：倾诉文本会发送至用户配置的 AI 端点。
- AI 上下文仅包含当前倾诉、工友性格和最多一条相关记忆，不发送薪资、备忘、打卡或整库历史。
- API 密钥不写入本地数据文件；开发运行通过环境变量提供，打包 Demo 可在当次运行时输入并仅保留在内存。
- 支持手动删除单条记忆和清空所有记忆瓶。

## 9. 异常与降级

- AI 无配置、超时、限流、网络失败或输出为空时，在 8 秒内切换到本地共情模板，不向用户暴露技术错误。
- 本地写入失败时保留当前内存状态，并在设置中显示“本次变更尚未保存”，不假装成功。
- 系统休眠、时间跳变或计时器延迟后，所有金额和倒计时根据当前绝对时间重算，不依赖累加的 `setInterval` 次数。
- 窗口恢复时校验当前显示器可见工作区；副屏拔除或 DPI 变化后将窗口拉回主屏。
- 系统通知不可用时，仍保留工友气泡和主窗口内提醒。
- 输入数据在写入前统一验证：月薪必须为有限正数，工作时间必须产生正的有效工作时长，发薪日限制在 1–31。

## 10. 测试与验收

### 10.1 自动化测试

- 薪资：上班前、工作中、午休、下班后、非工作日、月份切换和闰年。
- 发薪日：本月未到、本月已过、29/30/31 日跨月、周末不调整。
- 番茄钟：开始、暂停、恢复、重置、系统休眠后校准。
- 记忆：写入、重启恢复、7 天窗口、仅提起一次、删除。
- 提醒：多事件同时到期时的优先级与去重。
- AI：正常回应、超时、空回应、错误状态和本地兜底。

### 10.2 Demo 验收标准

1. Windows 启动后出现可拖动悬浮工友，点击可反复展开和收起主窗口。
2. 今日工钱在有效工作时间内持续增长，午休暂停，不因窗口隐藏或系统休眠累积误差。
3. 用户可完成一次倾诉，获得真实 AI 或本地兜底回应，关闭重开后记忆仍在且可被主动提起。
4. 番茄钟、打卡、备忘录、久坐和喝水提醒均存在可演示的完整交互。
5. 发薪日、下班和整点广播可通过演示模式立即触发。
6. 无 AI 密钥或断网时不阻断任何本地功能。
7. 全局快捷键可隐藏并恢复所有演示窗口，托盘可找回应用。
8. 最新自动化测试、类型检查和 Electron 冒烟测试通过，再宣布 Demo 完成。
